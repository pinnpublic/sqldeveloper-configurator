# SQL Developer Configurator 3.5.1

SQL Developer 편집기에 **노트 배경·글줄 선**을 추가하고, 방향키 이동과 편집 반응성을 개선했습니다.

## 새 기능

- **환경설정 → 코드 편집기 → 노트 배경**에서 공책·모눈·점 격자 등 12종 무늬와 종이 질감을 선택합니다.
- 모든 글줄 아래 10종 선의 색상·두께·진하기·간격을 조절합니다.
- 라이트·다크 종이색, 추가 줄 간격, 현재 줄 강조 불투명도를 설정합니다.
- 기본 선택 동작과 SQL 원문을 유지하며 기존 `---` 구분선과 각각 설정할 수 있습니다.

## 수정 · 성능

- 줄 간격이 추가된 상태에서 아래 방향키가 같은 줄에 머물던 문제를 수정했습니다. Oracle의 실제 방향키·선택·페이지 이동 동작이 표시 행 높이를 사용합니다.
- 자동 줄바꿈의 짧은 표시 행 끝에서 다음 행으로 건너뛰거나 위 방향키가 멈추던 경계 처리를 수정했습니다.
- 매 좌표 조회·그리기 때 실행되는 native `updateMetrics`에서 캐시를 지우던 처리를 제거했습니다. 문서 revision·글꼴·너비·접기 변경에 맞춰 캐시를 갱신합니다.
- 줄바꿈을 끈 상태의 줄 간격은 native 좌표의 직접 변환을 사용합니다. 줄바꿈을 켠 상태에서는 변경되지 않은 줄의 너비 계산을 재사용합니다.
- 현재 줄·선택 강조 변경으로 편집기와 전체 스크롤 영역을 다시 배치하던 처리를 정리했습니다. 주기적인 설정 파일 읽기는 별도 스레드에서 수행합니다.
- 구분선은 화면에 필요한 범위만 그리며, 그리기 중 불필요한 문서 전체 복사를 제거했습니다.

같은 1,000줄 메모리 문서 테스트에서 좌표 조회 20회 234→0.15ms, 화면 그리기 3회 65→3ms로 줄었습니다. 실제 DB 서버 실행 시간은 측정하지 않았습니다.

## 설치 · 업데이트

1. SQL 작업을 저장하고 SQL Developer를 종료합니다.
2. 아래 **SQLDeveloperConfigurator.exe** 또는 실행용 ZIP을 내려받습니다.
3. Configurator에서 설치본을 선택하고 **적용**한 뒤 SQL Developer를 실행합니다.
4. **도구 → 환경설정 → 코드 편집기 → 노트 배경**에서 원하는 표시를 설정합니다.

앱 3.5.1 / 확장 0.14.0. Windows · SQL Developer **26.2.0.186.2220** 지원. 기존 글꼴·결과표·노트 배경 설정을 유지합니다. Configurator는 패치 적용·업데이트·복구를 담당합니다.

실제 Oracle 컴포넌트와 메모리 문서로 방향키·Shift+방향키 24개 조합, Page Up/Down, 10,000줄 문서와 10,000개 구분선, 편집 후 원문 보존 및 기존 기능 회귀를 검사합니다. 실제 DB 쿼리는 실행하지 않습니다.
