# SQL Developer Configurator v3.4.0

- SQL 편집기·결과셋 글꼴 최대 **50pt**
- 결과셋 행 높이와 상하 여백 조절
- 자동 줄바꿈 및 `---` 수평선 표시
- SQL Developer 환경설정에서 선 두께·색상·모양 설정
- 설치 경로 자동 검색, 원본 백업·복구

**사용 방법:** SQL Developer 종료 → `SQLDeveloperConfigurator.exe` 실행 → 설치본과 글꼴·여백 선택 → **적용** → SQL Developer 실행.

**지원:** Windows 10/11 · SQL Developer **26.2.0.186.2220** · .NET Framework 4.8 · Java 17 이상.

다운로드: **EXE** 단독 실행 / **ZIP** 실행 파일·사용 설명서 포함. 자세한 설정은 [사용 매뉴얼](https://github.com/pinnpublic/sqldeveloper-configurator#readme)을 참고하세요.
