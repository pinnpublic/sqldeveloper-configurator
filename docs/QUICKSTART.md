# SQL Developer Configurator 사용 방법

지원: Windows / SQL Developer **26.2.0.186.2220** / .NET Framework 4.8 / Java 17 이상.

## 적용

1. 작업을 저장하고 SQL Developer를 종료합니다.
2. `SQLDeveloperConfigurator.exe`를 실행합니다.
3. 자동 검색된 설치 위치와 버전을 확인합니다. 찾지 못하면 **직접 선택**에서 `sqldeveloper.exe`를 선택합니다.
4. 편집기·결과셋 글꼴 크기와 결과셋 여백을 정하고 **적용**을 누릅니다.
5. **SQL Developer 실행**을 누릅니다.

편집기는 7~50pt, 결과셋은 6~50pt를 지원합니다. 여백은 위·아래 각각 -20~30px이며 기본값은 8px입니다. 큰 글꼴에는 양수 여백을 사용하세요.

설치 후 **도구 → 환경설정 → 코드 편집기 → 글꼴**에서 크기를 바꾸고 **확인/적용**하면 질의 결과의 크기와 행 높이도 함께 바뀝니다. 결과표 글꼴 종류와 여백은 유지합니다.

## 자동 줄바꿈·수평선

Developer의 **도구 → 환경설정 → 코드 편집기 → 자동 줄바꿈 · 수평선**을 엽니다.

- 자동 줄바꿈과 수평선은 각각 켜거나 끌 수 있습니다.
- 선 두께는 1~50px, 색상은 색상 선택 창 또는 `#RRGGBB` 입력으로 정합니다.
- 실선·파선·점선·일점쇄선·긴 파선·짧은 파선·이점쇄선·긴 일점쇄선·이중선 중에서 선택할 수 있습니다.
- **확인/적용**하면 열린 편집기에 반영되고, **취소**하면 저장하지 않습니다.

수평선은 앞뒤 공백을 제외하고 `---`만 있는 줄에 표시합니다. 화면에서 원래 하이픈은 숨기고 원문은 유지합니다. 하이픈 하나를 지우거나 줄을 삭제하면 선도 사라집니다. 문자열, 블록 주석, 다른 문자가 있는 줄에는 표시하지 않습니다.

## 다른 PC·업데이트·복구

다른 PC에는 실행 파일 하나를 복사해 같은 순서로 적용합니다. 필요한 글꼴은 해당 PC에 설치되어 있어야 합니다.

업데이트도 Developer를 종료하고 새 도구에서 **적용**합니다. 원본 백업은 유지됩니다. 되돌리려면 Developer를 종료한 뒤 **원본 복구**를 누릅니다.

원본과 설정을 백업한 뒤 적용하며, 지원 빌드·파일 상태가 예상과 다르면 중단합니다. 이 도구는 SQL 문서를 편집하거나 DB 쿼리를 실행하지 않습니다.
