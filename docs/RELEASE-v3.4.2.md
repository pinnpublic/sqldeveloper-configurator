# SQL Developer Configurator 3.4.2

- Developer 환경설정 → 코드 편집기 → 자동 줄바꿈 · 수평선의 두께 범위를 **1~50px**로 확장했습니다.
- 기존 실선·파선·점선·일점쇄선에 긴 파선·짧은 파선·이점쇄선·긴 일점쇄선·이중선을 추가해 **9종**을 제공합니다.
- 50px 선을 볼 수 있도록 미리보기를 넓히고, 두꺼운 선의 가장자리가 다시 그려질 때 누락되는 문제를 수정했습니다.
- 설정 패널의 색상 입력칸 너비 배분을 수정했습니다.

SQL Developer를 종료하고 새 실행 파일에서 **적용**한 후 다시 실행하세요. 선 두께와 모양은 **도구 → 환경설정 → 코드 편집기 → 자동 줄바꿈 · 수평선**에서 조절합니다.
