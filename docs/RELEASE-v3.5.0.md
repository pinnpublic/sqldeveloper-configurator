# SQL Developer Configurator 3.5.0

Eclipse Paper의 노트 배경을 SQL Developer Java 데스크톱판 26.2 편집기에 추가했습니다.

- **환경설정 → 코드 편집기 → 노트 배경**: 12종 배경, 36종 질감 선택(없음 포함), 라이트·다크 종이색.
- 모든 글줄 아래 10종 선, 색상·진하기·두께·간격·추가 줄 간격.
- 현재 줄 강조 불투명도와 기본 선택 배경 유지.
- 자동 줄바꿈·행 번호·접기 여백의 행 간격 연결. SQL 원문·복사 내용은 유지.
- 기존 `---` 구분선과 독립된 설정. 기존 글꼴·결과표 설정 및 원본 복구 지원.

앱 3.5.0 / 확장 0.13.0. 설치·업데이트 전에는 SQL Developer를 종료합니다.
